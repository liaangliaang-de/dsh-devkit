# 安装与数据

适用范围：已在 Windows DSH 0.2.1-rc.1 桌面验证。其他宿主版本尚未独立确认。

## 安装包

下载 GitHub Release 中的 ZIP 并解压。图形方式：DSH → 插件 → 添加插件，选择其中的 tgz。脚本方式：完全退出DSH（含托盘），运行 `Install.cmd`；脚本先校验SHA-256并备份profile配置，再调用DSH自带CLI离线添加，不运行安装生命周期脚本。

唯一可见条目是 dsh-devkit，根组件也只有一个。TypeScript和playwright-core是包内库，不是额外DSH插件。不需要安装组合矩阵中的压缩、记忆或技能插件才能使用本包。

**已知安装问题：** 在含既有插件的实际profile中，离线包管理器可能因旧依赖版本的本地元数据不完整而拒绝整个添加操作；本次出现过 billion-context@0.1.202 无法重新解析。隔离profile安装通过不代表所有日常profile离线安装都通过。不要因此删除旧插件或重建整个 .dsh。维护者本机采用经校验的独立本地目录、标准 link 依赖和单 bundle 条目安装，并验证了运行；这种回退尚未做成通用自动安装器。脚本失败时请保留诊断并提交不含个人信息的最小报告。

## 数据与权限

状态、回执原文和材料缓存默认在 `DSH_HOME/devkit`，没有设置DSH_HOME时位于用户目录 `.dsh/devkit`。截图和下载在项目 `.devkit-artifacts`。这些目录可能含项目源码和业务数据，按项目数据保管，不要直接上传公开仓库。

浏览器功能使用本机Chrome/Edge。受测机器在workspace-write模式下Chrome crashpad/OpenProcess拒绝访问，实际浏览器验收会失败；插件不自动切换权限。初始导航支持本地文件及loopback HTTP，不是通用联网浏览器隔离方案。

项目以“停止”“先别动”“等一下”等表达停止受管修改；已经发生的副作用不自动撤销。恢复前应核对未知执行结果。更换版本前保留状态备份；不承诺未来状态格式可向旧版降级。

## 停用与卸载

在插件条目中停用或卸载，已做过真实桌面验证。也可完全退出DSH后运行 `Uninstall.cmd`。卸载保留项目文件、状态及日志。配置备份在目标desktop profile的 `devkit-backups/时间戳`。包管理器若因既有依赖解析失败，停止操作并检查备份，不删除整个profile。
